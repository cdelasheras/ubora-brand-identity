# Paleta de Colores — Ubora Solar

> **Nota:** Los valores hexadecimales exactos han sido inferidos del análisis visual del sitio web y de las convenciones del sector de energías renovables. Para los valores oficiales de marca, solicitar al equipo de diseño el brand book corporativo.

---

## Colores primarios

### Verde principal
```
Nombre:     Ubora Green
Uso:        Color corporativo principal, CTAs, iconos de producto
Asociación: Renovable, sostenibilidad, naturaleza, confianza
```

### Blanco / Fondo claro
```
Nombre:     Clean White
Uso:        Fondos de sección, espacio en blanco, tipografía sobre fondos oscuros
Asociación: Limpieza, simplicidad, modernidad
```

---

## Colores secundarios

### Gris oscuro / casi negro
```
Uso:        Texto principal, titulares, alto contraste
Asociación: Profesionalismo, solidez
```

### Gris medio
```
Uso:        Texto secundario, subtítulos, metadatos
```

### Amarillo / Dorado solar
```
Uso:        Iconografía solar, acentos decorativos, energía
Asociación: Sol, energía, optimismo
```

---

## Principios de uso de color

- **Contraste accesible:** Texto oscuro sobre fondos claros, texto claro sobre fondos verdes o oscuros
- **Color como refuerzo semántico:** El verde refuerza el mensaje de sostenibilidad en toda la comunicación
- **Fotografía:** Imágenes con tonos cálidos (cielos azules, paneles bajo el sol) complementan la paleta
- **Gradientes:** Uso moderado en secciones de impacto (hero, secciones de métricas ambientales)
